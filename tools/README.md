# Инструменты 8AIC — калибровка и конфигурирование по Modbus TCP

Два эквивалентных клиента для настройки и калибровки модуля 8AIC
(8× 4–20 mA, АЦП `ADS1220`):

- `calibrate.mjs` — Node.js 18+, без внешних npm-пакетов
- `calibrate.py` — Python 3.8+, только стандартная библиотека

Оба реализуют встроенный Modbus TCP клиент и одинаковый диалог.

## Зачем нужна калибровка

Модуль измеряет `I_raw = code/2²³ × V_REF / R_shunt`. Допуск шунта (0.1 %),
ошибка опоры REF5020 (0.05 %) и деление 1 kΩ / входное сопротивление АЦП
(~0.05 %) снимаются поканальной линейной моделью:

```
I_true = gain × I_raw + offset        (mA)
```

Коэффициенты находятся методом наименьших квадратов по ≥ 2 точкам от
прецизионного источника/калибратора тока.

## Одноразовая запись (write-once) — читать перед калибровкой

Коэффициенты в регистрах `540 + ch×4` — **живой предпросмотр** (до
перезагрузки). Постоянное хранение — команда **COMMIT** (`HR131 = 0xCA00 | ch`),
которая программирует слот канала в отдельном секторе Flash и **блокирует его
навсегда**. Инструмент после расчёта спрашивает подтверждение — нужно набрать
слово `COMMIT`. Любой другой ответ оставляет предпросмотр без фиксации.

Разблокировать можно только аварийным стиранием всего сектора
(`HR132 = 0xC1A5` + удержание кнопки `FACT_RES`), см. README репозитория.

## Порядок калибровки одного канала

1. Подключите калибратор тока к клеммам канала (`AIn+` / `GND_ISO`).
2. Включите канал и запустите:
   ```
   node calibrate.mjs set --ch 0 --enable 1 --ip 192.168.1.13
   node calibrate.mjs calibrate --ch 0 --ip 192.168.1.13
   # или
   python calibrate.py calibrate --ch 0 --ip 192.168.1.13
   ```
3. Для каждой точки: выставьте ток на калибраторе, введите его в mA,
   инструмент усреднит `I_raw` (8 отсчётов). Наберите ≥ 2 точки
   (рекомендуется 3: **4, 12, 20 mA**), затем `done`.
4. Инструмент вычислит `gain/offset`, покажет максимальную невязку и запишет
   коэффициенты как предпросмотр.
5. Проверьте невязку; если устраивает — наберите `COMMIT`.

Во время калибровки канал должен быть в режиме 4–20 mA либо 0–20 mA — на
`I_raw` это не влияет; точки ниже 3.6 mA в режиме 4–20 будут помечены как
FAULT (обрыв), но `I_raw` при этом корректен, пока АЦП не насыщен.

## Другие команды

```
# Статус: ток, сырой ток, int16 и процент, код АЦП, флаги, блокировки
node calibrate.mjs status
python calibrate.py status

# Настроить канал
node calibrate.mjs set --ch 0 --enable 1 --range 4-20 --smooth 1
python calibrate.py set --ch 1 --enable 1 --range 0-20

# Скорость АЦП: 0 = 20 SPS + FIR 50/60 Гц, 1 = 90 SPS, 2 = 330 SPS
node calibrate.mjs rate 0
python calibrate.py rate 1
```

Параметры по умолчанию: `--ip 192.168.1.13 --port 502 --unit 1`.
